# バレエ打 - The Classical Theater -

クラシックバレエの演目や用語をタイピングして鑑賞満足度を高めるタイピング能力測定ゲームです。

## 概要
- **チケット＆鑑賞満足度システム**: B席（3,000円）、A席（6,000円）、S席特別ガラ（12,000円）から座席を選択し、タイピングによってチケット代以上の鑑賞バリュー獲得を目指します。
- **演目・登場人物（120語）**: 『白鳥の湖』『くるみ割り人形』『眠れる森の美女』『ドン・キホーテ』『ジゼル』などの幕構成や主要人物アンサンブルを網羅。
- **舞台演出**: 本物の劇場の板張り舞台フロアの上で、ピンスポットライトの光輪に包まれながらダンサーやモチーフがシルキースムーズに舞い踊ります。

## 起動方法
```bash
npm install
npm run dev
```
ブラウザで `http://localhost:3000` にアクセスしてください。

## テスト＆検証
```bash
npm run test
npm run lint
npm run build
```
